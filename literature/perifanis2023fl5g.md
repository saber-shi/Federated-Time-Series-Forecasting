# Federated Learning for 5G Base Station Traffic Forecasting

- Year: 2023
- Source: Repository README

## Relevance

This is the core benchmark paper for the repository. It frames the non-IID federated forecasting problem over 5G base-station traffic and motivates the baseline architectures and aggregation methods already implemented here.
